Header buttons

These two get a button beside Lock instead of a card in the grid, and each needs its own Ente public link. There can be only one of each. Unticking removes that album; use Move to the grid to keep it as a card.

    Albums in the grid

      Add an album to the grid

      Paste the embed snippet Ente gives you, or just the album link. Both are read, and the host does not matter — albums.ente.com, embed.ente.com and a custom domain all work. A link with only ?t= and no # is accepted too. Everything added here is a card in the grid; the two header buttons are edited separately above.

      3. Re-encrypt and download

      Leave that unchecked and the new file is encrypted with the same password you loaded the database with. Tick it to set a different one.

      Passwords are held in this page's memory only. Nothing is written to cookies, localStorage or sessionStorage, nothing is sent anywhere, and the fields are emptied once they are no longer needed.

      Then publish it: replace albums.enc.json in your repository with the file you just downloaded and push to main. The site serves whatever is committed there, so nothing changes until you do.
